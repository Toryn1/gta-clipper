Anleitung

Twitch-Zuschauer clippen ständig die lustigsten und krassesten Momente. Diese Seite sammelt diese Clips und sortiert sie nach Aufrufen. Was oben steht, ist meistens auch gut.

1. Clips finden

  1. Klick auf einen Schnellstart-Knopf, z.B. „🔥 Beste der letzten Stunde“.
  2. Klick auf ein Vorschaubild, um den Clip direkt abzuspielen.
  3. Gefällt er dir: „Auswählen“. Unten erscheint eine Leiste mit deiner Auswahl.

2. Die Filter (optional)

  • Zeitraum: aus welcher Zeit die Clips sein sollen. Danach „Clips laden“ drücken.
  • Sprache: z.B. nur deutsche Streamer.
  • Min. Views: blendet unbeliebte Clips aus. Siehst du nichts, stell es auf 0.
  • Max. pro Streamer: damit nicht alle Clips vom selben Streamer kommen. 0 = unbegrenzt.
  • Gesehene ausblenden: versteckt Clips, die du schon angeschaut hast.

3. Clips herunterladen

Dafür brauchst du einmalig das Gratis-Programm yt-dlp.

  1. Terminal öffnen: Cmd + Leertaste, „Terminal“ tippen, Enter.
  2. Einmalig installieren (falls du Homebrew noch nicht hast: brew.sh): 
    brew install yt-dlp
  3. In den Ordner wechseln, wo die Clips hin sollen, z.B. Schreibtisch: 
    cd ~/Desktop
  1. Startmenü → „Terminal“ oder „PowerShell“ öffnen.
  2. Einmalig installieren: 
    winget install yt-dlp
  3. In den Ordner wechseln, wo die Clips hin sollen, z.B. Desktop: 
    cd ~\Desktop

Danach jedes Mal: Clips auswählen → unten „⬇ Download-Befehl kopieren“ → im Terminal einfügen (Cmd + V bzw. Ctrl + V) → Enter. Die Clips landen im Ordner clips, benannt als „Streamer – Titel“.

4. Beim Posten

  • Nenn den Streamer immer gut sichtbar (im Video und in der Beschreibung). Der Name steht im Dateinamen.
  • Bearbeite die Clips etwas: Untertitel, eigener Titel, Zusammenschnitt. Das bringt mehr Reichweite.
  • Bei Streamern, die du oft nutzt: kurz um Erlaubnis fragen. So vermeidest du Copyright-Strikes.

Probleme?

  • Keine Clips sichtbar: Min. Views auf 0 stellen oder einen längeren Zeitraum wählen.
  • „Login abgelaufen“: einfach nochmal einloggen, das passiert nach ein paar Stunden.
  • Anderes Spiel: oben bei „Spiel“ den Namen ändern, z.B. „Fortnite“, dann „Clips laden“.
